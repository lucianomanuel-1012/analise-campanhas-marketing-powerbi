 Análise de Campanhas de Marketing com Power BI

 Sobre o projecto

Este projecto apresenta uma análise de dados de campanhas de marketing desenvolvida no **Microsoft Power BI**, a partir de uma base de dados organizada numa planilha Excel.

O relatório foi construído para explorar características dos clientes, padrões de comportamento, resultados de compra e hábitos de consumo, permitindo visualizar diferentes dimensões dos dados através de páginas interactivas.

 Objectivo

Explorar os dados de clientes e compras para compreender melhor:
- O perfil dos clientes;
- O comportamento de compra;
- A relação entre características dos clientes e os gastos;
- Os resultados de compra e os canais utilizados;
- A distribuição dos gastos por categorias e províncias.

 Ferramentas utilizadas

- Microsoft Excel — fonte dos dados.
- Microsoft Power BI — análise, modelação/organização visual e construção do relatório interactivo.

 Estrutura do relatório

O ficheiro Power BI contém quatro páginas de análise:

 1. Visão Cliente
Explora características dos clientes, incluindo:
- Estado civil;
- Escolaridade;
- Salário anual;
- Número de compras na loja;
- Número de compras na Web;
- Número de compras via catálogo;
- Número de compras com desconto.

Inclui também um filtro por província.

 2. Visão comportamento
Analisa aspectos do comportamento dos clientes, com visualizações relacionadas com:
- Gastos totais e número de filhos em casa;
- Gastos totais e número de adolescentes em casa;
- Relação entre salário anual e gastos totais;
- Decomposição dos gastos por estado civil e escolaridade.

 3. Visão campanhas
Apresenta análises relacionadas com a variável de compra (`Comprou`), incluindo:
- Distribuição dos registos por situação de compra;
- Salário anual em função da situação de compra;
- Comparação da situação de compra por número de filhos;
- Tabela de análise por escolaridade, estado civil, província e visitas ao website.

 4. Visão ponto de venda
Explora os gastos por província e categorias de produtos, incluindo:
- Gastos com alimentos;
- Gastos com vestuário;
- Gastos com utilidades;
- Gastos com electrónicos;
- Gastos com móveis;
- Gastos com brinquedos;
- Evolução dos gastos totais ao longo da data de cadastro.
